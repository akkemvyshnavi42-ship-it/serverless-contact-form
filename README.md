# Serverless Contact Form

## 📌 Project Overview
The Serverless Contact Form is a simple, responsive web application that allows users to send messages through a contact form. It features a clean and user-friendly interface built using HTML and CSS.

The project can be integrated with serverless services such as Formspree or AWS Lambda to process form submissions without managing a traditional server.

## 🎯 Objectives
- Create a simple and attractive contact form.
- Provide an easy way for users to send messages.
- Design a responsive interface for desktop and mobile devices.
- Explore serverless technologies for handling form submissions.

## ✨ Features
- Responsive design.
- User-friendly interface.
- Name, email, subject, and message fields.
- Clean layout with a modern design.
- Potential integration with serverless backend services.

## 🛠️ Technologies Used
- **HTML5** – Structure of the web page.
- **CSS3** – Styling and responsive layout.
- **Serverless Services (Optional)** – Formspree or AWS Lambda for processing submissions.
